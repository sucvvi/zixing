字醒 Windows beta2 启动故障排查

本版针对 beta1 在 Illustrator 启动阶段被列为“检测到插件问题”的反馈调整加载方式。
移除了启动阶段对旧版 AI Unicode String Suite、SP Blocks Suite 和 Adobe C++ 字符串对象的依赖。
使用只传递 C 类型的菜单注册接口；面板、OCR 与字体比较仍在点击菜单后才启动。
这些改动不是对所有 Illustrator 版本已经兼容的承诺，真实宿主仍需复测。

1. 先退出 Illustrator，把旧版“字醒.aip”移出所有增效工具扫描目录。
2. 如移出后可以正常启动，再退出 Illustrator，放入本版同名 .aip，确保没有重复安装。
3. 重新启动。如果成功进入 Illustrator，从“窗口 → 字醒”打开面板。
4. 如果仍提示“检测到插件问题”，请保留弹窗截图，并打开以下日志：
   %LOCALAPPDATA%\ZiXing\startup.log
   可以把上面的路径粘贴到 Windows 文件资源管理器地址栏。
5. 请提供日志全文、Windows 版本、Illustrator“帮助 → 关于”中的完整版本号。
   日志只记录加载阶段和错误码，不记录画布内容、账户或字体清单。

日志说明：
entry-startup：Illustrator 已经调用到插件入口。
acquire-menu-11 / acquire-access-3：宿主菜单 / 加载接口获取结果。
register-menu：创建菜单的结果。
startup-ready：菜单注册成功，启动流程已结束。
panel-created：用户点击菜单后，辅助面板进程已经创建。

如果没有新日志，说明可能尚未进入插件入口，需继续检查 DLL 加载、平台架构、文件完整性、系统拦截或宿主拒绝加载的原因。不能据此直接判定缺少 WebView2。
如果出现 startup-ready，但点击菜单后才失败，再检查面板与 .NET Framework 4.8 / WebView2。
不需要为排查而关闭安全软件、改动其他 Adobe 插件或重装 Illustrator。
