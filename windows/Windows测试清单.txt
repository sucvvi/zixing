字醒 Windows 2.1.0-beta1 实机测试清单

当前结论：下列 Windows Illustrator 项目全部待实测。编译成功不代表能在宿主中正常运行。

请记录：Windows 完整版本________，Illustrator 完整版本________，运行库版本________。
先只打开一个 Illustrator 版本，使用可丢弃的新文档。

[ ] 安装后无启动警告，“窗口 → 字醒”可见。
[ ] 字醒打开独立窗口，顶部显示所连 Illustrator 版本；关闭、再次打开正常。
[ ] 通过“文件 → 脚本 → 其他脚本”运行附带“创建测试样稿.jsx”，只创建新文档。
[ ] 在样稿中选中顶部转曲文字并识别；断网状态下也能识别，首次运行无模型下载。
[ ] 校对文字；匹配进度始终在顶部，完成后有可读候选；检查原字体能否进入候选。
[ ] 选择候选并恢复：新文字可编辑、更换字体，字号与位置合理，原稿仍可找回。
[ ] 选中底部三个可编辑文本框并合并：顺序“第一行 / 第二行 / 第三行”正确，保留样式。
[ ] 检查一步或多步撤销效果，无意外丢失原文；不承诺所有操作只占一个撤销步骤。
[ ] 空选区、只选图形、只选一个文本框均给出可理解提示，无崩溃。
[ ] 再次识别、编辑文本后重新匹配、关闭并重开面板均正常。
[ ] 关闭 Illustrator 后辅助窗口退出；重启 Illustrator 仍能打开。
[ ] 缺 WebView2、缺 .NET 4.8、安装文件夹只读时错误提示可理解（在独立测试环境做）。
