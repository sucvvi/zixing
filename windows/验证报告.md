# 字醒 Windows 2.1.0-beta3 验证记录

日期：2026-10-29。

## 用户反馈与边界

用户确认 beta2 已可正常启动，但 Windows 菜单显示乱码、字体候选准确度偏低。尚未提供 Windows / Illustrator 完整版本和匹配不准的字体样例。不能把一次用户启动反馈扩展为 2020–2026 全版本已验证。

## beta3 修订

- 先以 ASCII `ZiXing` 注册，再通过 Windows UTF-16 菜单 API 写入“字醒”；原生菜单不可用时保留可读英文备用名，不使启动失败，不请求旧 UnicodeString 套件。
- 字形校验与字形绘制使用同一个选中字体及 GDI glyph indices，不混用 GDI 字体检查与 GDI+ 自动文本排版。
- 对能够分开的连续汉字做逐字形状比较；对候选增加字距变体细排，并保留整体形状与笔画粗细约束。
- 字体恢复仍需本机安装且系统可读取的字体，不能把候选当成原字体确认。这里没有更换 OCR 模型，也不自动还原原字距。

## 验证方式

- 本地 15 项字形算法检查通过，包括字距变化后的分字、形状相同与粗细不同、拒绝强制拆分相连实心形状。
- 消息布局与菜单接口位置通过官方 Illustrator 2020 SDK 静态断言；未把 SDK 代码分发到仓库或成品。
- Windows 云端工作流使用 MSVC 构建，检查 DLL 加载、入口、原生菜单 UTF-16 名称以及其他菜单未被改动。
- Windows 字体回归采用 GDI+ 生成的独立参考图片，覆盖 4 种系统字体 / 字重和 5 档字距，比较 beta2 与 beta3 的排序。首轮结果：beta2 首选命中 17/20，beta3 命中 20/20，见 https://github.com/sucvvi/zixing/actions/runs/40826558142 。这个拉丁系统字体小样本不能当作通用准确率，尚无用户实际中文艺术字体的量化结果。

真实 Illustrator 中的 beta3 菜单、用户字体与恢复排版仍待复测。Windows 2022 的模拟宿主检查不代表所有 Windows 10/11 + Illustrator 组合都已通过。
