# 字醒 Windows 2.1.0-beta1 验证记录

日期：2026-10-28。状态：**可供实机验证的跨平台构建测试包，尚未通过 Windows Illustrator 实机测试**。

## 已完成

| 检查 | 结果与范围 |
| --- | --- |
| 原生插件编译 | LLVM-MinGW 输出 Windows x64 PE32+ DLL，导出 PluginMain；使用官方 Illustrator 2020 Windows SDK |
| 辅助窗口编译 | Roslyn 按 .NET Framework 4.8 参考程序集生成 x64 CLR WinExe |
| 包结构 | PiPL Windows 入口、内嵌辅助程序、离线模型、所有资源哈希与清单一致；无 SDK 源码、Mac 可执行文件；ZIP 完整性通过 |
| 动态依赖检查 | 仅 Windows 系统 / UCRT 导入，无额外 libc++、MinGW、VC++ 运行库 DLL；辅助窗口仍需 .NET 4.8 和 WebView2 |
| JavaScript 检查 | 30 项中 28 项通过、2 项平台夹具跳过；涵盖传输、字体候选状态、进度、坐标、恢复与合并的宿主模拟 |
| 纯字形比较 | 8 项通过：空白、边界、相同字形、微小位移、错误粗细、不同字形、归一化、尺寸校验 |
| 实际离线 OCR | 在 macOS Chromium 中运行此 Windows 包内相同的 Tesseract JS/WASM、简中/繁中/英文模型；仅图片桥接用测试夹具代替 |

实际 OCR 返回三行：英文 `Editable Type 2026`、中英混合 `修改字体 ABC 123` 正确；艺术字体一行误读为 `Fe HA SCF VRS Min`，置信度约 45%，标为需校对。该结果说明离线引擎可运行，也说明艺术字体识别能力不足。不能把这个浏览器测试写成“Windows OCR 已实机通过”。详见同包 `offline-ocr-observed.json`。

## 尚未验证

当前没有 Windows 电脑，以下均无实测证据：Illustrator 加载本 `.aip`、菜单回调、MinGW 与 Adobe 的接口兼容性、独立窗口启动、WebView2 本地虚拟域及 worker、COM 连接与脚本持久引擎、真实 GDI 字体枚举和字形渲染、文档恢复、合并、撤销及多次运行。

Illustrator 2020–2026 是兼容目标，全部版本均待测试；更早版本不在本版范围。Windows ARM64 和 32 位系统不支持。测试步骤见 `Windows测试清单.txt`。

没有商业 Authenticode 签名，运行时可能触发安全软件提示；未绕过系统防护。当前未改动用户 Mac 上安装的正式版、Illustrator 文档或 CEP 安全设置。

## 验证入口

- `windows/tests/verify-package.py`：解析生成的 PE、资源、导出和导入，并核对资源 / 二进制 SHA256。
- `windows/tests/runtime.test.cjs`：Windows 消息、坐标及连接约束检查；部分为模拟测试。
- `windows/tests/MaskChecks`：直接调用产品共用的 Mask 实现，不依赖 Windows GDI。
- `windows/tests/serve-ocr.py`：本地实际 OCR 浏览器测试，仅监听 127.0.0.1。
- `windows/build/build-manifest.json` 与 `package-verification.json`：当前构建记录，保留 `windowsIllustratorTested: false`。

本报告的通过结论仅覆盖上表的离机检查。正式发行应在 Windows 实机测试完成后再更新版本和兼容声明。
